# Implementation Plan

> 正本は `design.md`（2026-10-16 の設計の討議で確定・`research.md` 第 10・11 節）。テストは本番のファイルの兄弟（`*_tests.rs`）に置き、根と記憶の置き場は `TempPath::under_target`（ワークツリーの `target\test-roots\` の下）に作り、環境変数は値で注入する。足すテストは判断の分岐に限る（要件 12.7・12.8）。失敗の経路はどれも `error!`／`warn!` の記録を残す（黙る経路を作らない）。

- [x] 1.1 (P) 根の並びの値と、フォルダ名・根の 2 つの比べ方を目録の部品に足す
  - 一覧の項目（ゴースト・バルーン）に「どの根の下にあるか」の欄を足し、1 根の走査がそれを詰める。項目を直に組む bin のテスト（`boot_resolve_tests.rs`・`boot_resolve_balloon_tests.rs`・`ghost_switch_tests.rs`）は欄を足す 1 行ずつの直しだけ。シェルの一覧と単独の読み手（同梱のバルーン・名前の読み手）は変えない
  - 順の付いた根の並びの値（根 1 つの並びを作る口・今見つかる根を呼ぶたびに見直す口・見つかる根の `ghost\`／`balloon\` の列）を新しいファイルに置き、crate の入口から再輸出する
  - フォルダ名の同じ・違うの規則（1 字ずつ Unicode の単純大文字へ写し、2 字以上へ広がる字はそのまま）と、同じ根の規則（絶対化して末尾の区切りを落とした綴りを同じ規則で比べる・実体は見ない）を 1 つずつ持つ
  - 字の範囲の天井を `ponytail:` の注記で残す（NTFS の表と食い違ったら OS の比較へ替える）
  - 完了の姿: 兄弟のテストで、ASCII・全角英字・ギリシアの大文字小文字が同じと判定され `ß` はそのまま残ること、末尾の区切りや大文字小文字だけ違う根が同じ根と判定されること、見つからない根が「今見つかる根」から外れることが緑になり、今の目録のテストも緑のまま

  - _Requirements: 1.1, 1.2, 1.9, 2.8, 3.4, 3.6, 9.3_

## Implementation Notes

- 1.5: `areka-nar` は作業フォルダを根の綴りの完全一致でまとめる。同じ根を別の綴り（大文字小文字違い等）で答えると 2 つ目の掘りの掃除が 1 つ目の作業フォルダを消しうるので、4.5 の宛先の部品は 1 つの根に対してどの問いにも同じ綴り（並びの写しの綴り）を答えること。
- 2.1: design の `RootError` は控えを持たなかったが、要件 1.7・1.9・1.12・1.13 の warn を起動が失敗する経路でも残すため、各腕に `skipped`・`memory_fell_back` を持たせた（進行役の判断）。2.2 の記録の部品は失敗の値からも控えと「既定へ倒した」を warn に出すこと。`main.rs` の `mod roots;` の `#[allow(dead_code)]` は 3.1 で外す。
- 3.1: argv でゴーストを渡す起動では起動時の隠れの記録（`log_hidden`・`survey`）を出さない（要件 11.2「argv の起動は目録の外」と既存テストの「argv の起動は warn を出さない」を優先・`root_listed` は両経路で出す・テスト `boot_lists_roots_and_counts_hidden_only_without_argv` が固定）。要件 2.5 の欠けではない。
- 3.1: 移り途中の仮の形は `crate::roots::head_root`（見つかる先頭の根・無ければ先頭）1 つに集めた。使う所: `boot_config.rs`（2 か所・3.2）・`ghost_switch.rs` `running_name`（3.2）・`main.rs` `running_name`／後始末の告知（3.2）・`install/desk.rs` `GhostFacts.root`／`install/overwrite.rs`（4.5・4.6）。`install/procedure.rs` の `list_balloons(&BasewareRoot::new(facts.root))` も 4.6。7.1 で `head_root` ごと消す。
- 3.2: 格納フォルダの列を `; ` でつなぐ処理が `alert.rs::joined`・`boot_resolve.rs::joined`・`ghost_switch.rs::boot_into` の 3 か所にある。3.3 で告知の文面を仕上げるとき 1 つへ寄せてよい。
