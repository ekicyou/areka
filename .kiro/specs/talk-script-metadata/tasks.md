# Implementation Plan

- [x] 1. 土台: 付帯情報の型と、kanade と受け手への通り道
- [x] 1.1 台本の付帯情報の型を足し、台本の開始に欄を持たせる
  - 契約の層に、実行するゴースト（名と置き場）・置き場（ghost/master と最上位）・送り手（実行するゴースト自身／別のゴースト／道具）・それらをまとめた付帯情報の型を足し、再生の層の契約から再輸出する
  - 台本の開始に付帯情報の欄を足す。既定は「置き場が無い・名は空・送り手は実行するゴースト自身」で、今ある作り方（`StartTalk::new`）はこの既定を入れる
  - 再生の層の分解は付帯情報を受け取って捨てる（時刻の表には入れない）
  - 起動の挨拶と後書きだけのトークを直に組む本番の 2 か所（`boot.rs`）と、台本の開始を直に組むテストと支え（design.md の Modified Files に挙げたもの）に既定の付帯情報を足し、確かめる中身は変えない
  - 既定値と送り手の名の引き方（3 通り）のテストが通り、ワークスペース全体がコンパイルできる
  - _Boundary: TalkMeta, DriveMetaPassThrough_
  - _Dispatch: mechanical — 型と欄の形を設計が与え、既定値を足すだけ_
  - _Requirements: 1.1, 1.2, 1.5, 1.6, 2.1, 2.6, 4.4_

- [x] 1.2 kanade の設定にゴーストの置き場を持たせ、設定を組む所で絶対パスで埋める
  - kanade の設定に置き場の欄を足す（既定は無し＝試験の支え）
  - 設定を組む所が、ghost/master とその 2 つ上の最上位を絶対パスにして入れる。名の作りと最上位の取り方は一覧の名と同じ 1 つの手を使う
  - 絶対パスにできないときは警告を 1 行残して置き場を無しにし、起動は続ける
  - 同じウェーブの約束で、ゴーストの実行時の組み立て（`runtime.rs`・`runtime_tests.rs`）と Cargo の定義には触らない
  - 相対の根で組んだ置き場の組み立てから絶対の置き場が返り、名は前と同じであることをテストで確かめる
  - _Boundary: KanadeConfigPlace_
  - _Dispatch: mechanical — 欄を足し既存の名の作りに倣って埋める_
  - _Requirements: 1.3, 1.4, 1.6_

- [x] 1.3 受け手への口がトークの付帯情報も渡すようにする
  - トークの始まりの受け口に付帯情報の引数を足し、振り分け役が複製ごとに、そのトークの付帯情報を最初の合図より前に渡す
  - 受け口を自分で実装している受け手（バルーンの寿命・中断の旗）は引数を受けるだけで振る舞いを変えない。一括の実装に乗る受け手は何もしない
  - 付帯情報の型を結線の層から再輸出し、受け口の層（`areka-session`）が使えるようにする
  - 受け口を呼ぶ・実装するテスト（design.md に挙げた 6 本）を新しい引数に合わせる
  - 付帯情報を控える試しの受け手で、最初の合図より前に 1 回届くこと・違う付帯情報の 2 つのトークでそれぞれの複製がそれぞれを受けることがテストで通る
  - _Boundary: BootCueSinkMeta_
  - _Dispatch: mechanical — 引数の形を設計が与え、呼び手と実装を追随させる_
  - _Requirements: 3.3, 4.1, 4.2, 4.3_

- [ ] 2. 中核: 共通の決まりと、kanade で付帯情報を埋めること
- [x] 2.1 (P) 相対パスを解く共通の決まりを作る
  - 置き場・書かれたパス・探す順（ghost/master だけ／ghost/master → 最上位）だけで読むパスを決める純粋な決まりを再生の層に置く。在る無しは引数の判定で受け、通常版はファイルの在る無しを使う
  - 空は何より先に「空」、絶対パスはそのまま、置き場が無い相対は「置き場が無い」、どこにも無いと最後に試した候補を返す。`..` は繋いだまま正規化しない。環境変数の展開と本体のフォルダは入れない
  - 記録は出さない。理由の語（`empty_path`・`no_place`・`not_found`）を引ける
  - 結線の層の受け口のモジュール（`sink.rs`）から再輸出し、受け口の層が使えるようにする（再輸出の 1 行だけ）
  - 在るパスの集合を判定に渡すテスト（ファイルを読まない）で、探す順 2 通り・絶対・`..`・空・置き場が無い・どこにも無い・記録 0 件が通る
  - _Boundary: TalkPath（と `sink.rs` の再輸出 1 行）_
  - _Depends: 1.1_
  - _Dispatch: standard — 新しい分岐の決まりを組む_

  - 置き場つきの設定で一歩を駆動すると、定常の応答の台本の開始が設定の名と置き場を持つことがテスト（出口の規則の兄弟のテストのファイル・2.4 が足していく）で通る

- [ ] 2.3 (P) 台本を作る腕が送り手を決める
