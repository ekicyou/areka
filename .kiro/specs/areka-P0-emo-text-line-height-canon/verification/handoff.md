## 表 3: e2e が知っておくとよい注意（落とし穴になりうるところ）

| # | 注意 | 内容 |
|---|---|---|
| 1 | **`\_l` が描画範囲の遠辺付近へ跳ぶと折り返す** | `\_l` で行内位置を描画範囲の遠辺近くまで進めた直後の文字は、従来は描画範囲の外に置かれていたものが折り返されるようになりました。要件 6.4 は「折返しの位置を変えない」と書きますが、これは通常の折返し（折返し基準が決める位置）を指し、**要件 6.2（描画範囲の外に文字を置かない）を優先**する読みで決着しています。既存テストへの影響は 0 本（台帳 §7 の #12） |
| 2 | **警告の `balloon` 欄はバルーン名ではない** | 表 1 #6 の警告のバルーン名の欄は定数 `(名前なし)` です。`descript.txt` の `name,` は実在しますが、balloon パーサが名前を写していないため取得口がありません。**引受先は `areka-P0-ukadoc-survey-assets`**（2026-09-06 登記済み・台帳 §7 の #10） |
| 3 | **要件の「行」は視覚上の段、配置層の「行」は行矩形** | 要件 5.2 の「4 項目 3 行」は**段**の数です。配置層（`PositionedLine`）で数えると `\_l` が同じ段を別の行矩形に分けるため 4 本になります。行数を数えて何かを判断する場合は「行矩形の本数 ≠ 段数」を前提にしてください（台帳 §7 の #13） |
| 4 | **`draw.rs` は 988 行**（上限 1,000 まで残り 12 行） | 再走の過程で `crates/areka-emo-text/src/draw.rs` に何かを足す必要が出たら、先に分割の要否を検討してください。分割は次の spec（`areka-P0-text-decoration-canon`）の最初の作業として登記済みです |
| 5 | **観測用 example の実走手順（拡大率 1.0 の固定）** | `__COMPAT_LAYER=DPIUNAWARE` を付けて `emo-text-layer` を横書き・縦書きとも走らせ、ログに `scale_k=1.0` が出ていることを確かめてから `PASS` を読みます。この実走は自動テストの完了条件とは別の手動確認です（要件 11.8・要件 10.4 の「実機走行」には含めません） |
| 6 | **`spine_conformance_script.rs` の説明文が旧式のまま** | `crates/areka/src/emo2_boot/spine_conformance_script.rs` の「走行 A の症状 #1」を説明する節が、行送り 35px を**現在形**で述べています。本仕様の着地で 35px は 30px になったため、この記述は履歴になりました。本仕様の担当範囲の外（要件 2.4 の検査対象は `areka-emo-text` 側）なので触っていません——**e2e の再走時に見直してください**（`verification/task-6.1-sweep-and-tests.md` §1.6 が申し送りの正本） |
