## 軽微な所見（不整合ではないが記録する）

以下は FAIL とすべき不整合ではないが、透明性のため記録する。修正は本セルでは行わない（本タスクは確認・記録専任）。

1. **W7a/W7b の LOC が S4 名目値をわずかに超過**: W7a 2,630 / W7b 2,700 LOC は名目2,600を超えるが、S4 定義は「約2,600行」であり design.md が明示的に適合扱いとしている。両領域とも T セル事前分割と NEEDS_SPLIT フォールバックで緩和済み。
2. **事前分割サブセルの番号形式の表記差**: design.md の例示は `17.1a/17.1b`、tasks.md の実採用は `17.1/17.2`。例示（「例:」）に対する表記選択であり、分割の実体は design.md の規則（ファイル部分集合への分割）に準拠。
3. **design.md 普遍手順層内の周辺記述における具体名言及**: Orchestrator 節の Implementation Notes（Risks）に「cargo のワークスペース単位ビルドロック」、Security Considerations に「（Rust 文脈）」と明示した点検対象列挙がある。いずれも手順（やるべきこと）ではなくリスク説明・プロファイル文脈の補足であり、R7.4（普遍手順の作業記述が特定言語・ビルドシステムに依存しないこと）には抵触しないと判断。移植時はプロファイル節・領域表とあわせて読み替え対象となる。
