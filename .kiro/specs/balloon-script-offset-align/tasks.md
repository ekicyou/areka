## Implementation Notes

- `cargo clippy -p areka-placement --all-targets -- -D warnings` は既存のコード（areka-parsers の `shell/decode.rs`・placement の既存のファイル 20 件）で赤。各タスクの関門は「触ったファイルに新しい警告が無い」（`--no-deps` で確かめる）。
- 2.1 の向きの `debug!` の文が「3 つ目以降」と言うが、実際は ID の後（2 つ目以降）の引数を記録している。直すのは任意で、振る舞いは変わらない。
- 2.2 の `is_script_placed`・`overlay_offset`・`overlay_align` は 3.1・4.1 で呼び手が付くまで dead_code の警告が出る。`relative_saturates` は何もしない実装でも通るので、飽和しない軸が変わることの確かめを足すとよい（任意）。
- 2.3 の `script_world` は `DefaultPlacementBasis` を World に入れる（入れ物は World だけが持つ）。左の画面の DPI 144 は `MONITORS` にだけあり、窓を左へ動かすテストは窓の `DPI` を自分で入れる。
- 3.1 の `resolve_scopes` と `Layer` は reseed.rs の私有。4.4 で寸の差し替えを使うときは `pub(crate)` へ広げ、差し替えの枝のテストを 4.4 で足す。`resolve_descript_scopes`・`ScriptShare`・`script_share` は 4.x で呼び手が付くまで dead_code。
- 4.1 の当て口は `BalloonUserMoved` があっても今は標準へ据え直し、利用者のずらしが消える。4.2 で差の式と印の付け直しを入れて直す。`landed` は 4.4 まで記録に載るだけ。
- 4.2 の離しの記憶は `is_script_placed` が真のときだけ `script_share` を引く（GhostWindows の無い既存の組み立てを今のまま通すため）。記憶の入れ物の確かめは `crate::persist::finalize_save_tests::Store` を呼ぶだけで使う。
- 4.4 の着地前の印は `ScriptBalloonUnsettled { provisional }`（仮の大きさの標準を持つ・設計を合わせて改めた）。寸の変化の据え直しはバルーンのドラッグ中は飛ばす。ドラッグ中の飛ばし・`not_resolved`・解き直しの警告の 3 つはテストで固定していない。
- 5.1 のずらしの命令を断る警告の `reason` は `OffsetArgReason` の Debug の形（`MissingAxis` など）で出る。向きの腕は `"missing_id"`。
- 5.3 の呼び手は DPI の相だけ。DPI で変わった寸が drain の後段の `reconcile_reported_sizes`（第 2 経路）で着地すると据え直しは走らない。台本の値のあるスコープはバルーン窓の DPI の巡に書き込みが 2 本（寸と据え直し）になり、`transition_judge_verdict.rs` の `WRITES_PER_WINDOW_MAX = 1` に触れうる。どちらも 7.2 の実機で見る。
