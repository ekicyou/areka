# リリースの手順の文書の洗い出し

`areka-P0-release-cycle` の 3 つの文書（`requirements.md`・`design.md`・`tasks.md`）から、次のどれかに従っている所を洗い出した記録である（要件 6.6）。1 か所を 1 行で書く。

- **ア**: 版上げで書き換えるファイルの数え上げ（一覧・数）
- **イ**: 差分の範囲の判定（`git status --porcelain` の `??` の行・`git add` の行・PR に載るファイル）
- **ウ**: Release の走りが作る物（本文・添付の数）
- **エ**: 版上げの PR の本文と、それを見せる承認 A
- **オ**: 公開の後の確かめ
- **カ**: 使う道具の列挙と、workflow・`tools/` を書き換えない決まり

洗い出しは 2026-10-11、作業の枝の先頭 `4bb7a536` の 3 つの文書を頭から終わりまで読んで行った。設計の「リリースの手順の文書の直し」の表は、読んだ後の突き合わせに使った（下の「設計の直しの表との突き合わせ」）。

場所は「何の行か」で指す（行の番号では指さない）。「決め」の「直す（表に無い）」は、設計の直しの表に載っていなかったが、洗い出しで見つけて直した所である。
