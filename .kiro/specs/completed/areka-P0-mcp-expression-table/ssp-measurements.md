## 3. `group` の無い平たいファイル（強奪君・Shift_JIS）

```

0,素
20,パーカー素
30,両手素
```

答え: 上の既定の 15 件のうち 20 が `|\0||パーカー素|\s[20]|` に替わり、末尾に次の 3 行が続く。

```

|\0||チラ見せ|\s[50]|
```

## 6. グループ名が空・`scope` 無し（クニグンデ乃至は屍の王女・Shift_JIS）

`group,` の下に 0〜10・15・16・18・19・25 と 100〜110・115・116・118・119・125（字下げはタブ・`scope` の行なし）。
答えは全行が `|\0||名前|\s[ID]|`。既定は、書かれていない 11（`\1-刮目`）と 20（`立て看板`）だけが ID の順の位置に入る。

## 8. `option,DisableNoDefineSurfaces`（ヤダヤダヤダ！・UTF-8）

`option,DisableNoDefineSurfaces` あり。`group,\0`（`scope,0`）に 0〜9・11〜15・100、`group,__disabled` に 10500 番台。
シェルの定義は `surface0-9,11-15`・`surface100`・画像 `surface00010.png`。19・20・25 は定義も画像も無い。

```
|\0|\0|笑顔|\s[9]|
|\0||\1-素|\s[10]|
|\0|\0|しゅん|\s[11]|
|\0|\0|真顔|\s[12]|
|\0|\0|んー|\s[13]|
|\0|\0|目閉じ微笑|\s[14]|
|\0|\0|困り微笑|\s[15]|
|\0||\1-歌|\s[19]|
|\0||立て看板|\s[20]|
|\0||歌|\s[25]|
|\0|\0|ヤダ|\s[100]|
```

定義の無い 19・20・25 も載る＝このオプションは表を変えない。グループ名 `\0` はそのままキャラクタ名の列に出る。
