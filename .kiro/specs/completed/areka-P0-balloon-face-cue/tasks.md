# Implementation Plan

- [x] 1. さくらスクリプト解析層でのバルーン面切替タグ取り込み
- [x] 1.1 裸形一桁指定の構文的な認識
  - さくらスクリプト字句解析の短縮記法機構を一般化し、バルーン面切替の裸形一桁指定（`\bN`）を、既存の待ち時間短縮（`\wN`）と同一の規律で構文的に認識できるようにする。
  - 一桁の面数字は取り込まれて本文へ出力されず、続く文字（例 `\b12` の `2`）は正当な本文として扱われる。
  - 数字を伴わない裸形・未閉じブラケット・角括弧付き2文字語（`\b2[x]`）は既存の非短縮規則のまま処理される。
  - 完了状態: 境界ケース（`\b1`／`\b12`／`\b2[x]`／裸 `\b`／未閉じ `\b1[`）と既存 `\w` 系テストが全て緑になる。
  - _Requirements: 1.2, 1.3, 1.6_
  - _Boundary: sakura lexer/decode 増分（字句解析）_

- [x] 1.2 面切替命令への取り込み（両形・不透明転写）
  - 面切替タグのデコード処理に新しい取り込み経路を追加し、ブラケット形（数値指定・名前指定とも）と裸形短縮の双方を、バルーン面切替を表す第一級の命令要素へ変換する。
  - ブラケット内容・非表示指定（`-1`）は範囲展開や数値化を行わず、記述されたとおりの文字列として保持する。
  - 完了状態: `\b[10]`（数値形）・`\b[バルーン１]`（名前形）・`\b[-1]`（非表示）・裸形の全パターンで、面切替命令が同一の忠実転写ルールで生成されることをテストで確認でき、既存タグのパース結果は一切変化しない。
  - _Requirements: 1.1, 1.2, 1.4, 1.5, 1.6_
  - _Boundary: sakura lexer/decode 増分（デコード）_
  - _Depends: 1.1_

- [x] 2. (P) 演出コマンド語彙へのバルーン面切替コマンド追加

  - 表示系（サーフェス消費）を担うコマンド分類の説明を更新し、名前が示す範囲にバルーン面が含まれることを明記する（挙動は変更しない）。
  - 完了状態: 新設コマンド種別を含めたコマンド種別の網羅数え上げテストと、往復変換（シリアライズ/デシリアライズ）テストが緑になり、既存のコマンド種別・配送対象は一切変化しない。
  - _Requirements: 2.1, 2.3_
  - _Boundary: dola cue CueCommand 語彙_

- [x] 4. seriko バルーン面契約
- [x] 4.1 (P) 面指定の解釈
  - バルーン面切替コマンドが運ぶ面指定を解釈する処理を新設する。数値指定は表示対象の面番号または非表示指示として判別する。
  - 名前指定（将来の名前解決を見込んだ形式）と、数値だが範囲外・不正な指定は、性質の異なる別種として型で区別する（alias 表は参照しない）。
  - 完了状態: 数値表示・非表示センチネル・名前指定・不正数値の各入力が、それぞれ正しい種別へ判別されることをテストで確認できる。

  - _Boundary: seriko バルーン面契約（面指定解釈）_
  - _Depends: 2_

- [x] 4.2 (P) 表示・非表示指令の契約
  - バルーン面の表示・非表示を表す指令の契約を新設する（既存のシェル面向け指令は変更しない）。
  - 完了状態: 新設された指令の型がテストから構築・照合可能であり、既存のシェル面向け指令の形は一切変化しない。
  - _Requirements: 4.1, 4.2_
  - _Boundary: seriko バルーン面契約（指令契約）_
  - _Depends: 2_

- [x] 4.3 per-scope バルーン面状態管理
  - バルーンスコープごとの面表示状態を、シェル面の状態管理とは別の場所で保持する仕組みを追加する。
  - 同じ面が既に表示中／非表示中の場合は指令を再発行しない冪等な振る舞いとし、状態が変化した場合にのみ表示・非表示の指令を生成する。
  - 完了状態: 新規表示／冪等な再表示／非表示／冪等な再非表示／非表示から表示への復帰／未知スコープへの非表示の各遷移がテストで確認でき、シェル面側の状態管理には一切影響を与えないことを相互独立テストで固定する。
  - _Requirements: 4.3, 4.6_
  - _Boundary: seriko バルーン面契約（状態管理）_
  - _Depends: 4.2_

- [x] 4.4 消費経路の配線
  - バルーン面切替コマンドの消費経路を配線する: 面指定の解釈結果に応じて状態を更新し、変化があった場合にのみ単一の発行点から表示・非表示の指令を発行する。
  - 名前指定は「未対応の正当な入力」として警告ログに記録し発行しない。不正な数値指定は「破損した入力」としてエラーログに記録し発行しない（シェル側の破損入力と同じ重大度に揃える）。
  - この配線は、コマンド種別を判別する既存の分岐（面指定を取り出してから処理する形）の外側に早期分岐として追加し、既存のシェル面切替コマンドの処理経路の形は変更しない。
  - 完了状態: 名前指定で警告ログが1回だけ記録され発行なしとなること、不正数値でエラーログが1回だけ記録され発行なしとなること、同一面への再指定で指令が再発行されないこと、シェル面切替コマンドとの混在時に双方が独立して記録されることを、ログ捕捉付きの同期テストで確認できる。
  - _Requirements: 4.1, 4.2, 4.3, 4.5, 4.6_
  - _Boundary: seriko バルーン面契約（消費経路）_
  - _Depends: 4.1, 4.2, 4.3_
