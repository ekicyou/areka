## 独立検証の結果（本レビューで採取・2026-08-14）

f32 経路（`num as f32 / den as f32` → f32 乗算 → ceil）と整数オラクル（`div_ceil`）を突合:

- **到達比の要素数 = 23**（作者 {72,96,120,144} × モニタ {96..288} の gcd 約分・重複排除）——D3 の期待値と一致。
- **6/5 = ちょうど 81 件・初出 v=25 → 31（正 30）／12/5 = ちょうど 81 件・v=25 → 61（正 60）／残り 21 比 = 全て 0 件**——D4 の固定期待値と全件一致。
- **上下界（結果 ≥ 真値・差 ≤ 1）の違反 = 0 件**（23 比 × 1..=1200 の全 27,600 評価）——R3.1/3.2 の前提が実在することを確認。
- 副次的所見: 検証初回に PowerShell の `/`（非整数除算）でオラクル側を誤る**まさに research.md §9.2 の較正トラップを再踏**し、整数オラクル必須という D2 の根拠を実地で追認した。設計がテスト内に置く較正 assert（`len() == 23`・6/5/12/5 の包含確認）は妥当である。

## Critical Issues（最大 3）

### 🔴 Critical Issue 1: 檻の注入点と本番搬送層の乖離が Revalidation Triggers に登記されていない（軽微・GO を妨げない）

- **Concern**: C3 のテストは `ScaleRatio::as_f32` → `ScaleContract::new` → `physical_extent` を貫通するが、本番では k が `TextSlotView.scale`（`read.rs:109`）→ `TextSlotBinding::from_view`/`new` を経由してから `ScaleContract::new` に届く。現状この中間層は f32 の素通し（正規化は `ScaleContract::new` へ委譲）ゆえ算術忠実性は成立しているが、将来 binding 層が scale を変換するよう変わっても本テストは緑のままである。design の Revalidation Triggers は `physical_extent`・`as_f32`・DPI 語彙の変化のみを列挙し、搬送層の変化を挙げていない。
- **Impact**: 低（現状は素通しで、変更時も既存の binding 系檻が近傍にある）。ただし「本番と同一の f32 経路」（D1）という主張の適用範囲が読み手に過大に見える余地がある。
- **Suggestion**: C3 のテストファイル冒頭 doc（または design の Revalidation Triggers）に「檻の到達範囲は as_f32 以降の算術であり、`TextSlotView`→`TextSlotBinding` の搬送は素通し前提。搬送層が scale を変換するよう変わった場合は本檻の外」と 1〜2 文で登記する。タスク生成時に反映すれば足り、design の再生成は不要。
- **Traceability**: R3.1/3.6（D1 の根拠記述）
- **Evidence**: design.md「Key Decisions D1」「Revalidation Triggers」「C3」

## Design Strengths

1. **固定期待値の全てが独立再計算で裏付けられた検証設計**: 整数オラクル（D2・循環回避）＋本番同一 f32 経路（D1）＋比集合の格子導出と要素数固定（D3）＋誤り件数・代表例の期待値固定（D4）という檻の構成は、裁定の 4 根拠（+1 側のみ・不可視・6/5 一点帰着・費用不釣合）のうちテスト可能な前提を過不足なく固定しており、本レビューの再計算で 81/81/0×21・v=25 代表・上下界の全期待値が実在と一致した。件数が割れたら裁定再審というトリガ設計も明快。
2. **スコープ規律の徹底**: 却下された実装（有理配管・アクセサ新設・署名変更・112 箇所追随）を Non-Goals で名指しし、式 `region.rs:119-121` への「1 文字も変更しない」を Out of Boundary に明記。R5（非回帰）の充足を「差分が doc 行のみであることの git diff 目視」という検証可能な手順へ落とし、実機サインオフ不要の根拠（[[areka-evidence-classes-static-equals-real-machine]]）まで引いている。Traceability 表は要件 26 項目を全てカバーする。
