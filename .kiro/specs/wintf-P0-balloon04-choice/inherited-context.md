# 親仕様からの引継ぎコンテキスト

> **親仕様**: `wintf-P0-balloon-system`
> **対象要件**: R10（選択肢表示）

---

## 参照すべき設計情報

### design.md

- **ChoiceContainer / ChoiceItem コンポーネント定義**: 選択肢コンテナとアイテムのコンポーネント構造
- **キーボードナビゲーション**: 上下キー / Enter による選択肢操作
- **ホバー / 選択状態管理**: hovered / selected 状態のビジュアルフィードバック
- **コンテンツ領域との統合**: BalloonContentArea 内での選択肢配置（テキスト下部領域）

### research.md

- **G11**: 選択肢のアクセシビリティ対応（キーボードナビゲーション）は P0 必須。フォーカスの概念を保持するが、Windows Automation API 統合は P1 以降

---

## 子仕様スコープ

- 選択肢テキスト表示と配置
- ホバー・選択状態のビジュアルフィードバック
- マウスクリック / キーボード（上下キー・Enter）での選択操作
- 選択結果をスクリプトエンジンへ返す機構（イベントシステム経由）
