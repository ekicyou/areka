## Implementation Notes

- 2.2: `underline.rs` の右から左の写し（原点から左へ幅を伸ばす）は、2.3（左から右の書体だけ）・2.6（縦書き）のどの檻でも実物と突き合わされない。縦書きの回し方（時計回り）は 2.6 の実 GPU の檻で確かめる。
- 2.3: `collect_underlines` は Draw の原点 (0,0) で集める。DirectWrite は画素への寄せでベースラインを `round(b·k)/k` に寄せるので、行の原点×k が整数画素でないと実際の字のベースラインと最大 1 デバイス画素ずれうる。2.5 で原点×k の整数性を確かめるか、描く原点を Draw に渡すか、実 GPU の読み戻しで捕まえる。DirectWrite は DrawUnderline の失敗を Draw の HRESULT で返さないので受け手が自分の失敗の欄を持つ。
