- [x] 1.1 置き方の道具を 1 本作る（ビルド → 置く・入れ替える → 後始末 → 動くかの確かめ）
  - 環境変数が空・空白だけ・絶対パスでない（`/c/…`・`\foo`・`C:foo` を含む）なら何も置かずに `FAIL home: …` の 1 行と終了コード 1 で終わり、値を端末へ出さず設定も変更もしない
  - スクリプトの在る作業木のソースを release でビルドし、作った実行ファイルの道筋は cargo の JSON の報せから UTF-8 のバイトとして読む（既存の UTF-8 の子プロセスの読み手を使う）。ビルドが失敗したら置き場所に触らず `FAIL build: cargo exit <n>` で 1
  - 新しいものを `.new.exe` で写し、今のものを `.old-<UTC>.exe` へ改名してから `.new.exe` を正しい名へ改名する。改名に失敗したら古いものを戻して `FAIL place: rename` で 1
  - 古い `.old*.exe`（前の形の `.old.exe` も）を消してみて、消せたら `OK removed …`、走っていて消せなければ `KEEP … (in use; run again later)` を出して続ける
  - 最後に置いたものの `--help` を呼び、`OK check: --help exit 0` で 0。状態のファイル（`state.json`・ロック・居る印・ログ・`status.md`）に触らず `clear` を呼ばない
  - 冒頭の注釈に使い方・出る行・終了コードを書き、注釈の外は ASCII だけ。どのフォルダから呼んでも同じに動き、今のフォルダを変えない
  - 出来上がりの姿: 道具が在り、`pwsh -NoProfile -File tools/encoding-check.ps1` が通り、一時の置き場所へ向けて 1 回走らせると `OK placed areka-impl-watch.exe` と `OK check: --help exit 0` が出て終了コード 0 になる
