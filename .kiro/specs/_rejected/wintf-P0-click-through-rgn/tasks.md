# Implementation Plan: wintf-P0-click-through-rgn

## Overview
SetWindowRgn ベースのクロスプロセスクリックスルー機能の実装。**実験的仕様**のため、Phase 0 で互換性を検証し、失敗時は全体を破棄する。

## Prerequisites
- Approved requirements.md and design.md
- Phase 0 の GO 判定後に Phase 1 を開始

## Implementation Tasks

### Phase 0: DirectComposition 互換性検証（GO/NO-GO 判定）

- [ ] 1. DirectComposition + SetWindowRgn 互換性プロトタイプの検証
- [ ] 1.1 最小限の検証プロトタイプを実装
  - WS_EX_NOREDIRECTIONBITMAP スタイルのウィンドウを作成
  - DirectComposition Visual を設定し、簡単な描画を表示（例: 単色矩形）
  - SetWindowRgn で画面中央の矩形のみ有効なリージョンを設定
  - 目視確認: (1) SetWindowRgn API が成功、(2) Visual 描画が維持、(3) リージョン外のクリックが他プロセス（デスクトップアイコン等）に貫通
  - _Requirements: 6.1, 6.2, 7.1, 7.3_

- [ ] 1.2 互換性検証結果の評価と GO/NO-GO 判定
  - すべての検証項目が成功した場合: **GO** → Phase 1 に進む
  - いずれかの検証項目が失敗した場合: **NO-GO** → 以下のいずれかを選択
    - DirectComposition を破棄し、レガシー描画（GDI+ / UpdateLayeredWindow）に切り替え
    - SetWindowRgn アプローチ全体を破棄し、代替案（プロセス間通信経由のクリック転送等）を検討
    - 本機能（クロスプロセスクリックスルー）を諦め、Requirement 7 を削除
  - 判定結果をログに記録し、次のアクションを決定
  - _Requirements: 6.3, 6.4_

> **CRITICAL**: Phase 0 で NO-GO と判定された場合、Phase 1 のタスクは実行しない。設計フェーズに戻るか、機能全体を破棄する。

---

### Phase 1: 本実装（Phase 0 が GO の場合のみ実行）

- [ ] 2. クリックスルーリージョンモジュールの基本構造を構築
- [ ] 2.1 (P) HRGN の RAII ラッパーとリソース管理を実装
  - 所有権を持つリージョンハンドルのラッパーを作成
  - Drop 時に HRGN を自動解放する仕組みを実装
  - SetWindowRgn 成功後は OS に所有権を移転し、解放をスキップ
  - _Requirements: 9.1, 9.5_

- [ ] 2.2 (P) グリッドスナップとリージョン構築の定数を定義
  - グリッドサイズ（デフォルト: 4x4 物理ピクセル）を名前付き定数として定義
  - タイマー ID とタイマー間隔（250ms）を定数として定義
  - 構成可能性を確保（単一定数で変更可能）
  - _Requirements: 1.1, 3.1, 3.3_

- [ ] 2.3 (P) エラーリカバリ用の状態管理を設計
  - リージョン更新の有効/無効を切り替えるアトミックフラグを定義
  - 連続エラーカウンタをアトミック変数として定義
  - ダーティフラグ（将来拡張用）をアトミック変数として定義
  - _Requirements: 8.3, 9.4_

- [ ] 3. エンティティ bounds からウィンドウリージョンを構築
- [ ] 3.1 ECS World からエンティティ情報を読み取る
  - GlobalArrangement と HitTest コンポーネントを持つエンティティをクエリ
  - HitTestMode が None 以外のエンティティの bounds を収集
  - HitTestMode が None のエンティティはスキップ（クリックスルー領域として残す）
  - _Requirements: 2.1, 2.2, 2.3_

- [ ] 3.2 座標変換とグリッドスナップを適用
  - スクリーン座標（GlobalArrangement.bounds）からウィンドウ相対座標に変換
  - WindowPos.position をオフセットとして使用
  - 各 bounds にグリッドスナップを適用（floor/ceil でアライン）
  - f32 → i32 キャストを実行
  - _Requirements: 2.4, 3.2_

- [ ] 3.3 矩形リージョンを生成して合成
  - 各エンティティの bounds から矩形リージョンを作成
  - アキュムレータパターンで全リージョンを OR 合成
  - 一時リージョンハンドルを即座に解放してリークを防止
  - 空リージョン（エンティティ 0 件）の場合は全領域クリックスルーとして扱う
  - _Requirements: 2.4, 2.5, 2.7_

- [ ] 3.4 構築されたリージョンをウィンドウに適用
  - SetWindowRgn で HRGN をウィンドウに設定
  - bRedraw=FALSE を指定（DirectComposition が描画を管理）
  - SetWindowRgn 成功後、HRGN の所有権を OS に移転
  - 失敗時はエラーログを出力し、互換性診断情報を含める
  - _Requirements: 2.6, 7.1, 7.2_

- [ ] 4. タイマーベースのリージョン定期更新を実装
- [ ] 4.1 タイマー設定と解除の機能を実装
  - ウィンドウ作成時に SetTimer を呼び出し、0.25 秒間隔でタイマーを設定
  - ウィンドウ破棄時に KillTimer を呼び出してタイマーを停止
  - SetTimer 失敗時は警告ログを出力し、クリックスルーを無効状態として続行
  - _Requirements: 1.1, 1.4_

- [ ] 4.2 WM_TIMER メッセージハンドラを実装
  - タイマー発火時にリージョン構築関数を呼び出し
  - ドラッグ状態を読み取り、ドラッグ中は全画面リージョン（NULL）に拡張
  - ドラッグ終了後は通常のリージョン構築に復帰
  - World borrow 失敗時はスキップし、次回タイマーでリトライ
  - _Requirements: 1.2, 1.3, 5.1, 5.2, 5.3, 5.4_

- [ ] 4.3 ウィンドウプロシージャにタイマーディスパッチを追加
  - WM_TIMER メッセージの match arm を追加
  - タイマー ID でフィルタリングし、クリックスルー用のタイマーのみ処理
  - 他の WM_TIMER との衝突を防止
  - _Requirements: 1.2_

- [ ] 4.4 ウィンドウライフサイクルフックにタイマー管理を統合
  - WindowHandle コンポーネント追加時にタイマー設定関数を呼び出し
  - WindowHandle コンポーネント削除時にタイマー解除関数を呼び出し
  - エラー処理を各フック内で実施
  - _Requirements: 1.1, 9.2_

- [ ] 5. エラーリカバリと自己修復機構を実装
- [ ] 5.1 (P) GDI API 恒久的エラーの検出と自動無効化
  - リージョン構築成功時にエラーカウンタをリセット
  - リージョン構築失敗時にエラーカウンタをインクリメント
  - 連続エラー 10 回でリージョン更新を恒久的に無効化
  - 無効化時はエラーログに「permanently disabled due to repeated GDI errors」を記録
  - 以降の WM_TIMER では early return してリージョン構築を試行しない
  - _Requirements: 8.4, 9.4_

- [ ] 5.2 (P) エラーケース別のログ出力とリトライ戦略
  - CreateRectRgn / CombineRgn 失敗: warn! レベルでログ、次回タイマーでリトライ
  - SetWindowRgn 失敗: error! レベルでログ、HRESULT コードと互換性診断を含める
  - World borrow 失敗: trace! レベルでログ、スキップ
  - エンティティ 0 件: 空リージョンを構築（ログ不要）
  - _Requirements: 6.3, 8.1_

- [ ] 6. レイアウト変更検知とダーティフラグ管理（将来拡張）
- [ ] 6.1* レイアウトシステム完了時のダーティフラグ設定
  - レイアウト更新完了後にダーティフラグを true に設定
  - タイマー発火時にダーティフラグを確認し、true の場合のみリージョンを再構築
  - リージョン構築後にダーティフラグを false にリセット
  - **注**: 本仕様ではタイマー毎に無条件更新するため、ダーティフラグは参照しない（将来拡張用インフラとして用意のみ）
  - _Requirements: 4.1, 4.2, 4.3_

- [ ] 7. 統合テストと互換性検証
- [ ] 7.1 (P) タイマー動作とリージョン更新の統合テスト
  - SetTimer → WM_TIMER 受信 → リージョン構築 → SetWindowRgn の一連フローを検証
  - タイマー精度（250ms ± 50ms）を測定
  - 複数エンティティの bounds が正しくリージョンに反映されることを確認
  - _Requirements: 1.1, 1.2, 1.3, 1.4_

- [ ] 7.2 (P) ドラッグ連携テストとリージョン拡張の検証
  - ドラッグ開始 → 全画面リージョン（NULL）に拡張されることを確認
  - ドラッグ中は通常リージョンが適用されないことを確認
  - ドラッグ終了 → 次回タイマーで通常リージョンに復帰することを確認
  - ドラッグキャンセル時も正しく復帰することを確認
  - _Requirements: 5.1, 5.2, 5.3, 5.4_

- [ ] 7.3 (P) クロスプロセスクリックスルーの実動作検証
  - HitTestMode::None エンティティ領域をクリックし、他プロセス（デスクトップアイコン）にクリックが貫通することを目視確認
  - HitTestMode::Bounds エンティティ領域をクリックし、クリックがキャプチャされることを確認
  - 複数エンティティの配置パターンでクリックスルー境界を検証
  - _Requirements: 7.1, 7.2, 7.3_

- [ ] 8. パフォーマンス測定と最適化判断
- [ ] 8.1 (P) リージョン構築時間のプロファイリング
  - エンティティ数を段階的に増加（10, 50, 100, 500）してリージョン構築時間を測定
  - 各ステップ（クエリ、座標変換、CreateRectRgn、CombineRgn）の時間を個別に計測
  - tracing span で計測データをログ出力
  - 16ms しきい値を超えるポイントを特定
  - _Requirements: 8.1, 8.2_

- [ ] 8.2* パフォーマンス比較用の無効化フラグテスト
  - リージョン更新を無効化する設定を用意
  - 無効化時と有効化時のアプリケーション応答性を比較
  - パフォーマンス劣化が許容範囲か判断
  - 許容範囲外の場合は設計フェーズに戻り、最適化または方式変更を検討
  - _Requirements: 8.3, 8.4_

- [ ] 9. ドキュメント更新とリジェクション手順の確認
- [ ] 9.1 (P) リジェクション手順の文書化
  - モジュール削除手順（ファイル削除 + 3箇所の変更取り消し）を記載
  - 無効化手順（set_region_updates_enabled(false) 呼び出し）を記載
  - 互換性失敗時の判断基準を記載
  - _Requirements: 9.3, 9.4_

- [ ] 9.2 (P) モジュール境界とインターフェースの最終確認
  - すべての関数が pub(crate) で外部に公開されていないことを確認
  - 依存関係が設計通り（ECS read-only, Win32 API 呼び出しのみ）であることを確認
  - 他モジュールへの影響がないことを確認
  - _Requirements: 9.1, 9.5_

## Notes

### Phase 0 の重要性
Phase 0 は本アプローチの成否を決定する **最重要タスク** です。DirectComposition + SetWindowRgn の互換性が確認できない場合、Phase 1 のすべてのタスクは無駄になります。**Phase 0 を最初に完了し、GO 判定を得てから Phase 1 に進んでください**。

### 並列実行可能なタスク
`(P)` マーカーの付いたタスクは並列実行可能です。ただし、Phase 0 の GO 判定前に Phase 1 のタスクを開始しないでください。

### テストタスクの優先度
`- [ ]*` マークの付いたタスクは MVP 後に延期可能です。ただし、Phase 0 の互換性検証（Task 1.1）とクロスプロセスクリックスルー検証（Task 7.3）は必須です。

### リジェクション時の対応
- Phase 0 で NO-GO: 全タスクを中止し、設計フェーズに戻る
- Phase 1 でパフォーマンス問題: Task 8.2 で判断し、必要に応じて設計見直し
- モジュール削除: Task 9.1 の手順に従って3箇所の変更を取り消し
