# Implementation Plan

## 進め方の決まり

- 画面の描き方を GPU の節へ切り替える（7.1）までは、今の CPU の合成の口と表示の道を残す。どのタスクの後もワークスペースのビルドとテストが緑のままで、各タスクは自分が壊すテストを自分で書き直すか取り下げる。CPU の合成の口を外すのは 7.6。
- 5.1 で「描けるか」が広がってから 7.6 までのあいだ、今の CPU の合成の道は新しく描ける語を `overlay` として転写する（移す途中だけの形・見え方の檻はかけない）。
- 移す前の答えと所要は、移す前に測る（1.1）。CPU と WARP の答えの差（研究の項目 R2）は、CPU の合成がまだ在るうちに測る（6.5）。
- 合成の画素のテストは WARP で ±1、GPU の在りかのテストは実 GPU。CPU で描く案は取らない。
