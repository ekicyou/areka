# M1 完成判定

本書は M1 の完成判定を 1 か所に束ねる文書である（`design.md` の D10 完成判定・Requirement 10）。

完成判定は 3 つで構成する（R10.1）。

- ⑴ ワークスペース全体のテストが成功で終わること（§2）
- ⑵ 依存の許諾の検査と第三者告知の生成が通ること（§3）
- ⑶ 適合検証項目表 20 項目の実機サインオフ（§4）

3 つの根拠はいずれも本書の §2〜§4 から辿れる（R10.5）。**⑶ は人間の判断であり、AI 単独で完成を宣言しない**（R10.4・R5.10）。日付と時刻はすべて日本時間で書く。
