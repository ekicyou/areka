## 4. 項目ごとの分析と手

### 4.1 (a) 壊れた訳をログに残す（要件 1）

**今の流れ**

- 状態を変える呼び出し: `change` → `load` → `parse` が `None` → `set_aside` → `Event::Recovered { backup }` を作り、ログの口へ渡す → 本物の口は `warn!(command, event = ?event, "[store] state file was broken; set aside")`。
- `status` と走っている待ち・見張り: どちらも `read_only` を通る（待ちは `WaitPort::read` → `read_only`）。`Broken` を返し、`error!(error = %err, "[store] read failed")`。`Broken` の文は `state file is broken; see impl-watch.log` で、訳が無い。直す所は `read_only` の 1 か所で、要件 1.3 の 2 つの経路が両方片づく。

**行と列が 0 になる穴**

`parse` は `from_slice::<Value>` で読んでから `from_value` で形へ写す。serde_json は `Value` から写すときの失敗に位置を持たない（`line()`・`column()` が 0）。そのため、要件 1.2 の「形が合わない」の行と列を載せるには、版の数字を見た後に、元のバイト列から `from_slice::<State>` で直に読み直す必要がある。読み直しは 1 回分の読みが増えるが、状態ファイルは小さい。設計で、`from_value` の失敗の行と列が本当に 0 であることを 1 本のテストで確かめてから形を決めるとよい。

**訳の種類の分け方**（要件 1.1 の 3 つ）

| 中身 | 今の扱い | 訳の種類 | 行と列 |
|---|---|---|---|
| JSON として読めない（途中で切れた・BOM 付きを含む） | `from_slice::<Value>` の失敗 | JSON として読めない | 在る |
| 版の数字が無い・数でない・一番外が表でない | `version` が `None` | 版の数字が無い | 無い（要件 1.2 も求めない） |
| 版は 1 だが欄が合わない | `from_value` の失敗 | 形が合わない | 直に読み直せば在る |

serde_json の失敗の種類（`classify()`）でも「読めない」（`Syntax`・`Eof`）と「形」（`Data`）は分けられる。

**訳を運ぶ手**

| 手 | 中身 | 良い所 | 気になる所 |
|---|---|---|---|
| A: 出来事に欄を足す | `Event::Recovered` に訳の欄を足す（`plan.rs` のデータの型。判断の規則は変わらない）。`read_only` の側は `Broken` に訳を持たせ、文（`Display`）は今のまま、ログの行に別の欄で載せる | 退避の行は、偽のログの口で常時テストが判定できる（要件 1.6） | `plan.rs` の型に 1 欄。既存のテストの `recovered_event` の見本が変わる |
| B: 口の層だけで別に出す | `load` の中で訳の `warn!` を別に出す | `plan.rs` に触らない | 要件 1.1 の「退避を知らせる 1 行に載せる」に合わない（行が 2 つに分かれる）。常時テストで判定できない |

`read_only` の側の `error!` の行は、どちらの手でも常時テストでは捕まえられない（4.8 と同じ理由）。値としての訳（`Err(Broken { … })` の中身）は常時テストで判定でき、ログの実ファイルに載ることは実機テストの ⑧ を広げて判定できる（要件 1.6 は実機テストでもよい）。

**食い違い**: 要件 6.2 は、設計書の末尾に残す理由を「閉じるには判断の核の回収の決まりを変える必要があり、この spec の範囲の外」と定めている。手 B があるので、この理由の文はそのままでは正しくない。閉じないことを保つなら、理由は「閉じる手は 2 つ。回収の決まりを変える手は範囲の外。居る印を排他の中で解く手は判断の核を変えないが、待ちの口の形と終わりの順を変え、実測の無い窓に対して変更の幅が見合わない」のように書き直す必要がある。手 B で閉じるなら、要件 6.1〜6.3 を「閉じる」へ書き替えることになる。手順書 365 行と完了した設計書 334 行は書き替えない約束なので、閉じた場合は、それらに「まれに起きる」と書かれたまま実物では起きなくなる。害は無いが、字と実物がずれる。
