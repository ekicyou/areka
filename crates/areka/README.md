# areka

Desktop mascot platform for Windows

## About

**areka** is Ukagaka (伺か) baseware for Windows: an alternative to SSP that follows [ukadoc](https://ssp.shillest.net/ukadoc/manual/) and runs existing ghosts, shells, and balloons. It is built on the wintf UI framework.

The crate on crates.io (0.0.1) only reserves the name and is not the way to install areka for end users: the 32-bit helper executable is not built by `cargo install`.

## Usage

See the repository README at <https://github.com/ekicyou/areka> for features, how to build the distribution zip, and usage.
