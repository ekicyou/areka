# 同梱の手の形のカーソル

areka が `system:hand`（手を開いた形）と `system:grip`（手を握った形）に出す絵と、その作り直しの手順と権利の記録です。
Windows の標準の形には「手を開いた形」「手を握った形」が無いので、areka が自前の絵を同梱します（要件 6.2）。
組み立て（`cargo build`）では絵を焼きません。コミットした `.cur` がそのまま `areka.exe` に入ります。

## 中身の一覧

| ファイル | 役目 |
| --- | --- |
| `hand.svg` | 手を開いた形の元の絵（2048×2048・黒の背景の上の白い手・指の間の黒い線を持つ）。焼き直しの入力 |
| `grip.svg` | 手を握った形の元の絵（同じ寸法・黒の背景の上の白い手）。焼き直しの入力 |
| `hand.cur` | 道具の出力。手を開いた形のカーソルのファイル（10 寸法・32 ビット） |
| `grip.cur` | 道具の出力。手を握った形のカーソルのファイル（10 寸法・32 ビット） |
| `README.md` | この文書 |

- `.cur` の中の寸法は 32・40・48・56・64・72・80・88・96・128 の 10 個です（Windows の拡大率 100〜300% の 25% 刻みの寸法と 128）。areka は窓の DPI の寸法に合う項目を選んで作ります。
- 各項目は 32 ビットの BMP（色の面と 1 ビットの覆い）です。背景は透明で、白い手のまわりに 1 px の黒い縁が付きます。
- 出力の `.cur` は手で直さないでください。SVG を直して道具を回し直します。

## 作り直し方

下のコマンドの `<リポジトリの絶対パス>` は、このリポジトリを置いた場所（例 `C:\home\maz\git\areka`）に置き換えてください。どのフォルダから打っても同じに動きます（道具は自分の在るリポジトリの `crates\areka\cursor\` だけを読み書きします）。

### 絵（SVG）を直したとき

1. `hand.svg`・`grip.svg` を直します。道具が読めるのは、`svg` の直下の `path` だけで、属性は `fill`（`#rrggbb`）と `d` だけ、`d` の命令は絶対座標の `M`・`L`・`C`・`Q`・`Z` だけです。ほかの書き方（相対座標の小文字の命令・`H`・`V`・`A`・`transform` など）は使えません。
2. 道具を回します。

   ```powershell
   pwsh -NoProfile -File <リポジトリの絶対パス>\tools\cursor-art.ps1
   ```

   先に 2 つの SVG を全部確かめ、読めない書き方があれば `FAIL input <ファイル>: <理由>` の行を出して終了コード 1 で止まります（`.cur` は書き換えません）。通れば `OK wrote hand.cur (10 images)`・`OK wrote grip.cur (10 images)` を出します。`.cur` は一時ファイルへ書けてから置き換えるので、途中で失敗しても今の `.cur` は壊れません。同じ入力からは同じバイトのファイルができます。
3. 直した SVG と `.cur` を一緒にコミットします。

### 道具そのものを直したとき

```powershell
pwsh -NoProfile -File <リポジトリの絶対パス>\tools\cursor-art.ps1 -SelfTest
```

このフォルダの SVG を写したもの（ワークツリーの `target\cursor-art-selftest\` の下）で、2 回作って同じバイトになること・読めない命令（相対座標の `h`）で止まることを確かめ、通れば `OK selftest (2 checks)`、通らなければ判定ごとに `FAIL selftest ...` を 1 行出します。このフォルダは書きません。

## 焼き方と当たりの点の決め方

道具は寸法ごとに次の順で焼きます。

1. SVG の `path` を GDI+ の経路に写します（`Q` は同じ形の 3 次ベジェにします。塗りの規則は SVG の既定と同じ nonzero）。
2. 白い塗り（輝度 50% 以上）の経路の外接矩形が、その寸法の正方形の内側 1 px を残して、縦横の比を保って収まるように倍率と置き場所を決めます。
3. 黒で埋めた画板に、全部の経路を元の色で滑らかに塗ります。
4. 画板の縁から、暗い画素（輝度 50% 未満）をたどって透明にします。縁から届かない手の中の黒い線は残ります。
5. 不透明な画素の 8 近傍にある透明な画素を不透明の黒にします（1 px の黒い縁）。
6. **当たりの点**（クリックの位置になる点）は、不透明な画素（黒い縁を含む）の外接矩形の中心です。寸法ごとに整数の画素で、端数は切り捨てます。手のひらの真ん中あたりになります。

## 出どころと権利

### 絵の出どころ

| 項目 | 内容 |
| --- | --- |
| 使ったモデル | fal の Ideogram Vector（SVG で出るモデル） |
| 生成した日 | 2026-10-29 |
| 絵柄の指定 | 開発者が「Windows 風」と決めた |
| 選んだ案 | 開いた手・握った手を 2 案ずつ作り、開いた手は `hand-a`、握った手は `grip-a` を開発者が選んだ（要件の段） |
| 写した元 | 仕様のフォルダの `cursor-art/hand.svg`・`grip.svg`（このフォルダの SVG はその写し） |

選んだ経緯は、仕様 `shell-mouse-cursor` の `requirements.md` の「要件討議で決めた点」の 6 に在ります。
