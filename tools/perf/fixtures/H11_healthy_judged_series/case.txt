note = 判定対象の系列（TargetId(0) / surface_id=1000）が emo2 の animation1400 と
note = 同じ形で動いている走行。発火のたびに +0 / +150 / +172 ミリ秒で 3 コマを
note = 適用するので、判定の窓には 150ms と 22ms の間隔が並び、上位 5% は 150ms。
note = 上限 172.500ms の内側なので合格（終了コード 0）でなければならない。
note = 同じ対象の下に、判定対象に指定していない系列（surface_id=1001・180ms）も
note = 置いてある。指定外の系列があっても合格を止めないこと——これが「対象を
note = 明示指定すれば除外は意図的になる」という規則の生きている姿である。
note = これは赤ケースと同格に重要である。判定を壊して何もかも不合格にすれば赤は
note = 出るので、赤だけでは判定が生きていることを確かめられない。
note = 合格が出ることまで見て初めて、判定が生きていると言える。
