ごきげんよう、[Claudia](https://github.com/ponapalt/claudia) ですわ。この版では、ゴーストの置き場を並べて持てるようになり、winget で入れても入れたゴーストと記憶が消えないようになりましたの。えみりも入って動くようになりましたわ。winget で 0.0.2 を入れた方と、環境変数 `AREKA_ROOT` を使っている方は、最初の 2 つの見どころを必ずお読みくださいまし。

### winget で入れても、入れたゴーストと記憶が消えなくなりますわ(#322)

winget で入れたときと、`areka.exe` のフォルダに書けないとき（Program Files の下に置いたときなど）は、後から入れたゴースト・バルーンと、areka とゴーストの記憶を、`%LOCALAPPDATA%\areka\` に置きますわ。これまでは `areka.exe` のフォルダの中に置いていましたので、winget で上げ直すたびに消えていましたの。置き場所は環境変数 `AREKA_USER_ROOT` で替えられますわ。

0.0.2 を winget で入れた方は、0.0.2 から最初に上げ直すときに、0.0.2 のフォルダの中に後から入れたゴースト・バルーンと、ゴーストの記憶が消えますわ。0.0.2 はこの置き場を持たないため、areka の側からは守れませんの。上げ直す前に、`ghost` フォルダと `balloon` フォルダを別の場所へ写しておいてくださいまし。areka 自身の記憶は残り、新しい版が引き継ぎますわ。

一度きりのお手数ですけれど、これからは上げ直しても安心ですわよ。

### ゴーストとバルーンの置き場を、いくつも並べて持てますわ(#317)

右クリックのメニューに「置き場を追加…」「置き場を先頭へ」「置き場を外す」が増えましたわ。SSP のフォルダを置き場に足せば、SSP のゴーストもそのまま一覧に並びますの。同じ名前のゴーストは、並びの上の置き場のものが使われますわ。新しく入れるもの（`.nar` で入れたものなど）は、並びの先頭の置き場に入りますの。

環境変数 `AREKA_ROOT` は、`;` で区切った置き場の並びとして読むように変わりますわ。名前に `;` を含むフォルダは、`AREKA_ROOT` では渡せなくなりますの。そのフォルダは、`AREKA_ROOT` を設定せずに起動して、メニューの「置き場を追加…」から足してくださいまし。

### えみりが入って、起動から終了まで動きますわ(#331, #332)

SSP に同梱のえみり（`emily4.nar`）を入れて、起動から終了まで動くところを確かめましたわ。同梱のバルーンの中身が書庫に無い `.nar` も入るようになり、そのバルーンだけを飛ばして、警告のダイアログを 1 つ出しますの。3 人目からのキャラクターの鍵（`char2` 以降）を持つゴーストでも落ちませんわ。ただし、3 人目からの窓はまだ出しませんの。

名前付きの `\![move,--X=…,--base-offset=…,--move-offset=…]` で窓が動くようにもなりましたわ。同梱の「えも？？」のメニュー「エモの位置調整」が効きますの。右クリックのメニューには「シェル位置初期化」が増え、`\![execute,resetwindowpos]` と同じく、窓を既定の位置へ並べ直しますわ。`--time` を付けた移動は、今は時間をかけずにすぐ動きますの。

### 吹き出しのリンク・口パク・動く絵が働きますわ(#286, #287, #261)

さくらスクリプトの `\_a[ID]` と `\_a` で挟んだ文字が、押せるリンクになりましたわ。押されたことは `OnAnchorSelectEx` と `OnAnchorSelect` でゴーストへ届きますの。SERIKO の interval の `talk,数値`・`runonce`・`periodic,数値` も動きますので、話している間の口パクが付きますわ。シェルの APNG と動く WebP の絵は、SERIKO の指定が無くてもそのまま動きますわよ。

### Claude Desktop から、ゴーストにつなげますわ(#290)

`areka.exe` の隣に、Claude Desktop と areka を取り次ぐ小さなプログラム `areka-mcp-bridge.exe` を同梱しましたわ。Node.js などを入れなくても、Claude Desktop の設定に登録するだけでつながりますの。登録の仕方は、areka を開いたまま、ブラウザで `http://127.0.0.1:9801/api/mcp/help` を開いてお読みくださいまし。arm64 の機械で中継が起きるかは、まだ実際の機械で確かめておりませんわ。

### crates.io の `dola` を使う方へ、合図の種類が 2 つ増えますわ(#286, #318)

crates.io に出している `dola` の合図の種類 `CueCommand` に、`AnchorBegin` と `AnchorEnd` の 2 つが増えますわ。`CueCommand` の全部の種類を `match` で並べ、`_` の腕を持たない利用側は、この版でビルドが通らなくなりますの。2 つの腕を足すか、`_` の腕を足してくださいまし。合図の受け手 `CueSink` には `choice_wait_began` が増えましたけれど、既定は何もしませんので、こちらは直さなくても動きますわ。

### 記憶を書けないときは、黙って続けずにお知らせして終わりますわ(#323)

areka の記憶を書けないときは、お知らせを 1 つ出して終わるようになりますわ（終了コードは 1 ですの）。これまでは黙って続けていましたので、前回のゴーストを覚えられないまま気付けませんでしたの。書けない場所へゴーストを入れようとして失敗したときも、壊れたファイルとしてではなく、書けなかったこととしてゴーストへ伝えますわ。
