ごきげんよう、[Claudia](https://github.com/ponapalt/claudia) ですわ。areka は、デスクトップにキャラクター（ゴースト）を住まわせる Windows 用のアプリですの。この版は、どなたにも zip で受け取っていただける初めての版ですわ。α 版ですので、できることはまだ限られますけれど、ゴーストを迎えて、替えて、新しくするところまでは、ひととおり揃いましたわよ。

### zip を展開して開くだけで、ゴーストが立ちますわ(#190, #218, #224)

この頁の添付に、x64 用と arm64 用の zip を置いておりますわ。展開して `areka.exe` を開くと、同梱のゴースト「えも？？」が立って、起動の挨拶を話しますの。`areka.exe` には署名がありませんので、開くときに Windows が警告を出すことがありますわ。arm64 用の zip は、実際の機械で開くところまではまだ確かめておりませんの。使い方と既知の制限は、zip の中の `README.txt` をお読みくださいまし。

### 右クリックのメニューから、ゴースト・シェル・バルーンを替えられますわ(#159, #177, #192, #205)

キャラクターを右クリックすると、メニューが出ますわ。「ゴースト」を選ぶと、今のゴーストが別れの台詞を話したあとに、選んだゴーストへ替わりますの。「シェル」と「バルーン」は、今のゴーストのままで替わりますわ。最後に使ったゴースト・シェル・バルーンは覚えておきますので、次に開いたときも同じ姿で立ちますわよ。

### `.nar` を入れて、ネットワーク更新で新しくできますわ(#158, #176, #198, #201, #203)

`.nar` ファイルは、メニューの「インストール…」で選ぶか、キャラクターの上へドラッグして落とすと入りますわ。入れた後は今のゴーストのままですので、新しいゴーストに替えるときは、メニューの「ゴースト」から選んでくださいまし。メニューの「ネットワーク更新」を選ぶと、今のゴースト・シェル・バルーンを、配布元の新しい版へ入れ替えますの。

### 里々と YAYA の標準のテンプレートも動きますわ(#146, #162)

同梱の「えも？？」（SHIORI は pasta）のほかに、里々と YAYA の標準のテンプレートのゴーストも、実際に動かして確かめましたわ。32 ビットの SHIORI は、同梱の `shiori-host32-helper.exe` の中で動かしますので、64 ビットの areka からそのまま使えますの。ただし、α 版の表現力は「えも？？」が普通に動く水準までですわ。ゴーストによっては、表情や演出の一部が欠けますの。

### Claude Code などの AI から、ゴーストの様子を読めますわ(#219, #223, #230, #232, #235, #242, #250)

areka は開いている間、自分の PC の中（`127.0.0.1`）だけで MCP サーバを待ち受けますわ。SSP の MCP サーバと同じ 10 本のツールのうち、読むための 7 本（今いるゴースト・状態・記録・プロパティの値・表情の一覧・今の見た目の画像 2 本）が働きますの。台詞を話させる `sakurascript`・イベントを送る `raise_event`・読み込み直す `reload` の 3 本は、この版ではまだ働きませんわ。つなぎ方は、areka を開いたまま、ブラウザで `http://127.0.0.1:9801/api/mcp/help` を開いてお読みくださいまし（9801 が使われているときは 9821 ですわ）。
